**Kebun Ajaib** — an original spot-the-difference game. Two near-identical fantasy garden pictures side by side: find the differences, click to mark them, use hints, race the clock, and advance through three levels (6, 7 and 8 differences). All art is drawn in code on canvas and all sound is synthesized with WebAudio; the game is static and works offline with no network requests.

## Run it

```sh
node serve.ts --port 8080
# then open http://localhost:8080
```
